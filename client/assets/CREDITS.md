# Third-party assets

All 3D models and sound effects in this folder are by **Kenney** (https://kenney.nl) and are
released under **CC0 1.0 Universal (public domain)**:
https://creativecommons.org/publicdomain/zero/1.0/

They were taken from Kenney's open-source starter kits on GitHub, whose READMEs state that the
included sprites, 3D models and sound effects are CC0 licensed:

| Folder | Source repository | Contents |
|---|---|---|
| `models/racing` | https://github.com/KenneyNL/Starter-Kit-Racing | pickup trucks, motorcycle, tents |
| `models/fps` | https://github.com/KenneyNL/Starter-Kit-FPS | blaster, blaster repeater, cloud |
| `models/arena` | https://github.com/KenneyNL/Starter-Kit-Basic-Scene (Mini Arena pack) | rigged soldier character, statue, column, banner, weapon rack, trophy, tree |
| `models/city` | https://github.com/KenneyNL/Starter-Kit-City-Builder | fountain, tree cluster |
| `models/platformer` | https://github.com/KenneyNL/Starter-Kit-3D-Platformer | flag |
| `sounds` | Starter-Kit-FPS, Starter-Kit-City-Builder, Starter-Kit-3D-Platformer, Starter-Kit-Racing | blaster shots, footsteps, jumps, landing, weapon switch, build placement/removal, breaking, pickup, impact, engine loop, ambience |

Attribution is not required by CC0, but thank you Kenney!

The UI font (Titillium Web) is licensed under the SIL Open Font License 1.1; see
